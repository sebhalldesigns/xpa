# xpa
Cross Platform App Library

## What is it?

xpa is framework for building graphically-intensive dock-style applications with a highly cross-platform architecture.
Uniquely, xpa combines the consistency of web UIs with the porformance of native applications, by rendering the UI as a translucent overlay on top of a native application window.
This architecture has partly been driven by the desire to treat the web as a first-class deployment target, and rendering UI within a web canvas tends to be less responsive and more resource intensive than native web controls.
